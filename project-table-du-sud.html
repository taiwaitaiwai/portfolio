Table du Sud E-Commerce

UX & UI Redesign for Search, Filtering & Custom E-Commerce Screens

Table du Sud e-commerce platform overview showcasing desktop, tablet, and mobile interface layouts.

During my time at a Dutch digital agency, I worked as a Junior UI Designer alongside a Senior Designer on the e-commerce redesign for Table du Sud, a premier Dutch custom furniture brand. Working in Sketch, our goal was to elevate the digital shopping experience to match the premium quality of their physical craftsmanship.

Beyond designing key interface screens across the platform, my primary focus was completely rethinking the search and filtering experience. By replacing plain text color labels with visual color swatches, we turned custom product discovery into an intuitive, tactile process for shoppers.

My Contribution

  • Redesigned search and multi-category filtering interfaces for e-commerce product discovery
  • Designed selected UI screens and interface layouts across the platform
  • Transformed plain text color selections into visual, intuitive color swatches
  • Created responsive UI layouts for Desktop (1680px), Tablet (834px), and Mobile (414px) viewports
  • Collaborated directly with a Senior UI Designer, Project Lead, and front-end developers in an agency workflow

What I Learned

Working on Table du Sud deepened my understanding of conversion-centered UX in e-commerce. Replacing text labels with visual color swatches demonstrated how subtle UI micro-improvements directly impact user intuition and purchasing confidence. It also taught me how to communicate design intent clearly across a multi-disciplinary team of designers, project managers, and engineers.

Responsive Layouts

The interface system was structured across three core device breakpoints: Desktop (1680 px), Tablet (834 px), and Mobile (414 px), ensuring consistent browsing, clear product presentation, and smooth filter drawer interactions across all screen sizes.

Search, Filtering & UI Detail Screens

The search and filter section was rebuilt to make customizing furniture effortless. In the original version, colors were listed as plain text strings. I introduced visual color swatches directly into the filter panel and product detail overlays, giving users an immediate visual preview of materials and finishes.
