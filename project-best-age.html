Best Age 50+ — Accessibility & UX Audit

Senior-Friendly Web Redesign Pitch, WCAG Compliance & Mobile Optimization

Concept slide overview for the Best Age 50+ website optimization and senior accessibility audit.

Best Age 50+ is a UX research and web optimization concept created for a specialized fitness studio for seniors. The audit identifies technical layout flaws, mobile usability barriers, and legibility issues on the existing website, proposing concrete solutions tailored to the ergonomic and visual needs of the 50+ demographic.

The project showcases client pitch preparation, Web Content Accessibility Guidelines (WCAG 2.1) adherence, and strategic visual restructuring designed to boost conversions and trust for older users.

Core Optimization Pillars

  • 1. Responsive Technical Layout: Replaced rigid, fixed column widths causing horizontal overflow with a flexible CSS Grid / Flexbox system and structured multi-column footer navigation.
  • 2. Streamlined Navigation: Consolidated an overcrowded 8-item navigation menu into 5 logical categories with submenus and an accessible mobile hamburger menu.
  • 3. WCAG Typography & Contrast: Replaced informal Comic Sans body font with Source Sans 3, increased base text size to 18–20px, and achieved a minimum 4.5:1 color contrast ratio (dark blue on crisp white).
  • 4. Content & Clear Call-to-Actions (CTA): Removed watermarked stock imagery in favor of authentic licensed graphics, adding high-visibility direct action buttons for phone and email registration.
