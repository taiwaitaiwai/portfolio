ZITRA Web App

Pop & Kitsch Mobile QR-Code Scanning Campaign for Organic Lemonade

ZITRA mobile web application overview showcasing the pop-kitsch aesthetic, brand character, and campaign navigation.

ZITRA is an interactive mobile web app campaign designed for a fictional organic lemonade brand ("Pur · Sauer · Echt"). The core feature of the app is an instant-win QR code scanner built directly into the mobile browser using Vanilla JavaScript and HTML5 camera stream integration.

The visual identity embraces a playful "pop & kitsch" style featuring a stylish, vibrant grandma character as the brand ambassador. Built strictly for mobile viewports, the web app dynamically adapts its layout structure when rotated between vertical (portrait) and horizontal (landscape) orientations, enhanced with keyframe CSS animations.

My Process & Contributions

  • Concept & Art Direction: Designed a retro-pop visual aesthetic using energetic sunburst backgrounds, custom typography, and the "trendy grandma" mascot.
  • QR Camera Integration: Integrated client-side camera access via JavaScript and the `jsQR` library to parse codes instantly without native app installation.
  • Adaptive Orientation System: Engineered CSS layout mechanics that smoothly reorient navigation bars and promotional cards when turning the phone landscape.
  • Interactive States & Micro-Interactions: Crafted custom win/lose result states, animated button states, and floating lemon graphics using pure CSS keyframes.
