LAPP Global B2B E-Commerce

UI Design & Design-System Support

LAPP Global B2B E-Commerce interface across desktop, tablet, and mobile breakpoints.

I joined the LAPP e-commerce project as a Junior UI Designer during its mid-stage in 2022. Working within an established UX concept and visual design system, I created selected interface screens and supported the maintenance and expansion of shared Sketch libraries, reusable components and icons.

The platform covered a wide range of B2B e-commerce areas, including product information, listings, search, account functions and purchasing workflows. My role focused specifically on UI production and maintaining visual consistency across different modules and responsive screen sizes.

Responsive Variants & Grid System

The interface system was built around a fluid 12-column layout designed across five distinct device breakpoints: Mobile Size XS (360 × 640 px), Tablet Size S (600 × 800 px), Tablet Size M (768 × 1024 px), Desktop Size L (1024 × 768 px), and Desktop Size XL (1366 × 768 px). This unified structure ensured that components, navigation modules, and complex data tables adapted seamlessly and predictably across all mobile, tablet, and widescreen viewports.

UI Elements & Component System

To support modularity and efficiency across the e-commerce platform, I worked with reusable UI components and design tokens. This included maintaining standard product tiles across responsive scales, defining interaction states (default, hover, pressed, disabled) for CTA buttons and interactive controls, and documenting tile teaser slots with fixed image ratios (16:9 and 4:3) to maintain visual consistency across marketing areas.
