Reichstag Ragnarok

2D Political Parody Fighting Game, Character Systems & AI Production Pipeline

Reichstag Ragnarok key visual featuring Fritz and Der Millionär in front of the blazing battle stage.

Reichstag Ragnarok: Pension Destruction is an experimental 2D parody fighting game currently in active development as a personal hobby project.

The project serves as a creative playground to explore game system design, character concepting, sprite animation pipelines, and generative AI workflows. Each character is being handcrafted with 300 to 400 individual sprite drawing frames to ensure fluid arcade animation in open-source fighting game engines like IKEMEN GO and Phase 5.
