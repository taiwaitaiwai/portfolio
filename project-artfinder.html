ArtFinder — Dynamic Art & Museum Database

Full-Stack Web Design, MySQL Relational Database & PHP CRUD Operations

ArtFinder web platform branding and dynamic art collection interface.

ArtFinder is a full-stack web application designed for exploring iconic artworks, historical master artists, and world-renowned museum collections. Built with a relational MySQL database backend and dynamic PHP integration, the platform features a complete CRUD (Create, Read, Update, Delete) workflow that allows registered members to manage records, insert new museums and artists, and attach artwork metadata.

The project emphasizes clean interface layout, clear form architecture, user authentication, and responsive visual presentations for art pieces.

Core Architecture & System Features

  • Dynamic Catalog Browsing: Queries the MySQL database to dynamically list artworks, artists, and associated museum locations.
  • Member Authentication System: Secure session handling (login_check.php and member.php) ensuring administrative tools are restricted to authorized users.
  • Relational Data Insertion: Dynamic forms (add_artist.php, add_museum.php, insert.php) connected to server-side processors (insert_do.php) to update database records seamlessly.
  • Modular Front-End UI: Custom styling and responsive UI layout (style.css) structured for optimal readability across various display sizes.
